# FunPay Factory: инструменты для продавцов FunPay на базе Cardinal

Мои плагины и материалы для [Cardinal](https://github.com/sidor0912/FunPayCardinal) - опенсорсного бота для продавцов FunPay. Если Cardinal у вас работает круглосуточно, эти инструменты добавляют ему несколько полезных дел.

Канал с новостями и разборами: [@funpay_factory](https://t.me/funpay_factory)

## Что здесь есть

| Продукт | Что делает |
| --- | --- |
| Монитор позиций (position-monitor/) | Следит за позициями ваших лотов в выдаче FunPay. Присылает в Telegram алерты, если лот опустился, конкурент выше стал продавать дешевле или лот пропал из выдачи. Утренняя сводка, команда /positions. |
| ИИ-автоответчик (ai-autoresponder/) | Отвечает покупателям в чатах FunPay с помощью нейросети. Подключается к любому OpenAI-совместимому API. Персона, прайс и FAQ настраиваются, есть fallback-текст и кулдаун. |
| Бот-ассистент настройки Cardinal (setup-assistant/) | Отдельный Telegram-бот: ведёт по установке Cardinal с нуля (Windows или Docker) шаг за шагом, с ветками решения типичных ошибок и финальным чеклистом. |

Пошаговый гайд «Cardinal за вечер» продаётся отдельно лотом на FunPay - в репозиторий он не входит.

## Безопасность

Плагин работает на вашей машине, рядом с аккаунтом FunPay, и получает доступ к нему через Cardinal. Поэтому у вас должна быть возможность прочитать каждую строчку до установки. Что вы увидите в коде:

- плагины не отправляют golden_key и данные аккаунта никуда;
- нет телеметрии, счётчиков и скрытых запросов;
- единственное наружное соединение помимо funpay.com и Telegram - LLM-endpoint в ИИ-автоответчике, который вы сами указываете в настройках. Туда уходят только тексты сообщений, и только когда автоответчик включён. Не нужен автоответчик - не настраивайте его, остальные инструменты работают полностью локально.

Нашли проблему - открывайте issue, поправлю.

## Установка

Требования: работающий Cardinal (Python 3.11.0). Дополнительных зависимостей нет - requests и bs4 уже входят в Cardinal.

Способ 1, через Telegram-бот Cardinal:

1. Откройте чат с вашим ботом, отправьте /menu.
2. Нажмите "Плагины", затем "Добавить плагин".
3. Перешлите боту файл плагина .py.

Способ 2, руками:

1. Скачайте .py файл нужного плагина.
2. Положите его в папку plugins/ рядом с Cardinal.
3. Перезапустите Cardinal.

Для ИИ-автоответчика дополнительно понадобится адрес и ключ любого сервиса с OpenAI-совместимым API (OpenAI, OpenRouter и другие). Ключ хранится только в вашем конфиге.

Бот-ассистент запускается отдельно от Cardinal: инструкция в setup-assistant/README.md.

## Структура репозитория

```

├── setup-assistant/    Бот-ассистент настройки Cardinal (aiogram 3)

└── LICENSE
```

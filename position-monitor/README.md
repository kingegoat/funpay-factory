# Монитор позиций (плагин Cardinal)

Продукт линейки Cardinal-фабрики. Плагин для [FunPayCardinal](https://github.com/sidor0912/FunPayCardinal),
который следит за позициями ваших лотов в выдаче FunPay и присылает алерты в Telegram.

Покупатель: продавец FunPay, у которого круглосуточно запущен Cardinal.

## Что делает

- Раз в заданный интервал читает выдачу раздела (`funpay.com/lots/<node_id>/`).
- Для каждого вашего лота считает:
  - позицию среди всех строк выдачи;
  - позицию среди строк без платного закрепа (`offer-promo`);
  - текущую цену (по атрибуту `data-s`, как и сама FunPay сортирует выдачу);
  - конкурентов выше: их позиции, цены, ники, закрепы.
- Присылает в Telegram владельца:
  1. алерт о падении позиции на M мест и больше;
  2. алерт о демпинге: конкурент выше вас стал дешевле вашей цены;
  3. алерт, если лот пропал из выдачи;
  4. утреннюю сводку раз в день: лот, позиция, дельта за ночь;
  5. мгновенный отчёт по команде `/positions` и справку `/pm_help`.

Никаких действий с чужими лотами плагин не выполняет, только чтение публичной выдачи.

## Установка

### Через Telegram-бот Cardinal (рекомендуется)

1. Откройте чат со своим ботом Cardinal.
2. `/menu` -> кнопка **Плагины** -> **Добавить плагин**.
3. Перешлите боту файл `monitor_positions.py` (не архив).
4. Плагин появится в списке. До перезапуска Cardinal команды могут не попасть
   в всплывающее меню команд Telegram, но `/positions` и `/pm_help` работают сразу.

### Вручную

1. Скопируйте `monitor_positions.py` в папку `plugins/` в корне Cardinal.
2. Перезапустите Cardinal.
3. В логе должна появиться строка `Монитор позиций запущен: ...`.
4. Отправьте боту `/pm_help` для проверки.

На Windows папка `plugins` лежит рядом с `Start.bat`, на Linux/Docker - в корне
рабочей директории Cardinal.

## Настройка

Всё настраивается в словаре `CONFIG` в начале `monitor_positions.py`,
после правки перезапустите Cardinal.

| Ключ | По умолчанию | Описание |
|---|---|---|
| `lots` | см. файл | Список лотов: `node_id` (раздел выдачи), `lot_id` (ID лота из ссылки `offer?id=`), `name` (имя для сводок). Можно несколько лотов из разных разделов. |
| `interval_min` | 10 | Интервал проверки выдачи, минут (минимум 1). |
| `drop_threshold` | 5 | Алерт, если позиция ухудшилась на это число мест и больше. |
| `summary_hour` | 9 | Час утренней сводки (локальное время). |
| `alert_cooldown_min` | 15 | Кулдаун повторных алертов одного типа на один лот, минут. |
| `competitors_in_report` | 3 | Сколько конкурентов выше показывать в отчётах. |
| `request_timeout` | 30 | Таймаут HTTP-запросов, секунд. |
| `fetch_fail_notify_after` | 3 | Алерт после N неудачных получений выдачи подряд (0 - отключить). |

Как узнать `lot_id`: откройте свою страницу выдачи в браузере, найдите свою строку,
наведите мышь на заголовок лота - в ссылке вида `funpay.com/lots/offer?id=32500000`
число и есть `lot_id`. `node_id` - число из адреса страницы выдачи (`/lots/1392/`).

Дельта в сводке: меньший номер = выше = лучше. Формат `3 → 5 (↓2)` значит падение
на 2 места, `5 → 3 (↑2)` - подъём. Дельта «за ночь» считается от прошлой утренней
сводки, а после перезапуска Cardinal - от первого замера (состояние в памяти,
после перезапуска история начинается заново).

## Как получаются данные

Сначала плагин пробует метод `cardinal.account.get_subcategory_public_lots()` из
FunPayAPI (порядок списка = порядок выдачи, цены, продавцы, закрепы). Если метод
недоступен или упал на изменившейся вёрстке, плагин сам скачивает HTML страницы
выдачи через сессию аккаунта и парсит его (`tc-item`, `tc-price`, атрибут `data-s`).
Строки, скрытые ленивой загрузкой (`lazyload-hidden`), тоже учитываются: в HTML они
есть сервер-сайд. Лоты в платном закрепе встречаются в выдаче дважды - берётся
лучшая (первая) позиция.

## Команды

- `/positions` - мгновенный отчёт: позиция лота, всего строк, позиция без закрепа,
  цена, ближайшие конкуренты выше.
- `/pm_help` - справка.

## Безопасность

- Плагин отправляет данные только на `funpay.com` (чтение выдачи через сессию
  вашего аккаунта) и уведомления через Telegram-бот Cardinal. Других внешних
  запросов нет, телеметрии нет.
- `golden_key` и любые данные аккаунта никуда не передаются и не логируются.
- LLM-эндпоинтов в этом плагине нет вообще, поэтому исключений из правила нет.
- Код открытый, можно проверить всё выше по файлу `monitor_positions.py`.

## Тесты

Парсер гоняется по синтетической фикстуре `fixtures/lots_1392_rows.html`
(структура реальной выдачи, все id и ники выдуманные; генератор -
`fixtures/make_fixture.py`):

```bash
python3 -m pytest tests/ -q
```

Нужны `beautifulsoup4` и `pytest`. Все чистые функции (парсер, поиск позиций,
детекция демпинга, кулдауны) покрыты тестами и не требуют запущенного Cardinal.

## Технические детали

- Python 3.10+, зависимости: `bs4`, `requests` (уже есть в Cardinal), `lxml`
  опционально (быстрее парсинг, без него используется `html.parser`).
- Поток мониторинга daemon, останавливается через `threading.Event`
  (`BIND_TO_PRE_STOP`), основной цикл Cardinal не блокируется.
- Логирование через `logging` (логгер `position_monitor`), без `print`.
- Команды регистрируются через `cardinal.add_telegram_commands(...)` в
  `BIND_TO_PRE_INIT`, чтобы попадать в меню команд Telegram того же запуска.
- Уведомления уходят через `cardinal.telegram.send_notification(...)`, то есть
  уважают настройки уведомлений вашего бота Cardinal.
- UUID плагина: `05026a8e-292a-46f3-b5b8-e485a87768b1` (фиксированный).
